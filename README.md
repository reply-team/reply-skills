# reply-skills

This repository is archived. Its three skill packs have each gone their own way:

- **Reply's skills** (`reply-adapter`) ship with [reply-cli](https://github.com/reply-team/reply-cli), inside its npm package `reply-cli`: `npm i -g reply-cli`, then `reply skills install`.
- **The SDR expertise** (`ai-sdr-core`) and **the runtime skills** live in [jason-ai](https://github.com/reply-team/jason-ai), in [`skills/business`](https://github.com/reply-team/jason-ai/tree/main/skills/business) and [`skills/runtime`](https://github.com/reply-team/jason-ai/tree/main/skills/runtime), and `jason skills install` installs them.
- **`agentic-runtime`** is retired; the runtime skills in jason-ai (`skills/runtime`) were written afresh around Jason's own API and are not a copy of it.

The packs stay in this repository's history, read-only. Plugin installs already made from this marketplace keep working and never update.
